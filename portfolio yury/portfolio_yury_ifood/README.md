## Como estou aplicando IA

O protótipo **Assistente IA para Achados e Perdidos** explora um fluxo de ponta a ponta:

1. Recebe uma descrição em linguagem natural.
2. Usa um modelo de linguagem para sugerir categoria, descrição padronizada e palavras-chave.
3. Compara essas informações com itens de exemplo e ordena possíveis correspondências.
4. Expõe o fluxo por uma API e uma interface web simples.

O objetivo é demonstrar integração de IA em um problema concreto, não apenas uma conversa com um chatbot.
